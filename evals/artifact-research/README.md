# artifact-research eval seeds

Model-routing seeds for canonical project artifact research. They cover baseline skill activation, schema-open exact metadata filtering, optional profile definitions/availability and confidence, bounded observed metadata, preview-index versus exhaustive-search routing, unfamiliar cross-domain ownership, and no automatic artifact creation. They include mixed Unity, Unreal, and custom schemas without a Unity-specific policy. Deterministic indexing/filtering/freshness behavior remains in package tests; live model trials are opt-in.
